A slice is also a view — it's a window into the original. Only these operations give you an independent copy:

OperationResultUse when

⚠ Deep Copy — object arrays only
For numeric arrays, .copy() is enough. Only use copy.deepcopy() when each cell holds a Python object (a list, a dict) — like a roster of club badges. For every marksheet you'll work with as an analyst, .copy() is sufficient.

Stacking Arrays

Section A and Section B sent marks separately. The principal needs one master sheet — with a totals column and a class-average row.

🧱 Stacking Demo — build the master sheet step by step
Start with step 1 →
Python
# Step 1 — vstack: add rows below (SQL: UNION ALL)
master = np.vstack([sec_a, sec_b])          # (4,3)+(4,3) → (8,3)

# Step 2 — hstack: add column to the right
totals = master.sum(axis=1)                 # shape (8,) — flat!
sheet  = np.hstack([master, totals.reshape(8,1)])  # reshape required

# Step 3 — vstack again: add average row at bottom
avg   = sheet.mean(axis=0)
final = np.vstack([sheet, avg])             # (8,4)+(1,4) → (9,4)
⚠ The reshape trap
totals has shape (8,) — a flat list. hstack sees it as 8 separate columns, not one column of 8 values. Always .reshape(8, 1) before stacking a computed column.
SQL Equivalent
np.vstack([sec_a, sec_b]) → SELECT * FROM sec_a UNION ALL SELECT * FROM sec_b
np.hstack([master, totals]) → JOIN totals ON position (no key — rows must already be in order)

Splitting Arrays

Every section head wants only their rows. Every subject teacher wants only their column. The printer needs 3 batches from 8 students.

Python
# vsplit — cut rows (axis 0)
sec_a2, sec_b2 = np.vsplit(master, 2)        # (8,3) → (4,3) + (4,3)

# hsplit — cut columns (axis 1)
maths, sci, eng = np.hsplit(master, 3)       # (8,3) → 3 × (8,1)

# uneven split: 8 ÷ 3 isn't equal → use array_split
# np.vsplit(master, 3)   # → ValueError!
batches = np.array_split(master, 3)         # → (3,3)+(3,3)+(2,3) ✓

Python
# one scheme: (8,3) @ (3,) → (8,)
overall = results @ weights
# → [79.5, 45.6, 96.4, 35.4, 71.2, 88. , 43.7, 94.8]

# two schemes at once: (8,3) @ (3,2) → (8,2)
both = results @ schemes

# who flips verdict between schemes?
passed = both >= 35
flips  = np.where(passed[:,0] != passed[:,1])[0] + 1  # → [4]
OperatorWhat it doesUse for
a * bElement-wise (with broadcasting)Scale each value independently
a @ bMatrix multiplicationWeighted scores, regression, ML
np.matmul(a, b)Same as @When passing as a function argument
np.dot(a, b)Same for 1D/2D; also accepts scalarOlder code you may encounter
🎯 Interview question
"Difference between * and @ in NumPy?"
* multiplies position-by-position (shape stays same, broadcasting applies). @ is matrix multiplication: row-meets-column, inner dimensions must match and disappear from the output shape.
05

NumPy vs Pandas

Riya tried to add a Section column to the marks array. Everything turned to strings. NumPy arrays hold one dtype — text wins and breaks the maths.

❌ NumPy — one dtype
Add a text column → entire array becomes <U32. results[0,0] is now the string '80.6'. Can't do maths.
✓ Pandas — one dtype per column
Numbers stay float64. Text column stays str. Labels, groups, joins — Pandas handles all of it.
Python — the bridge pattern
import pandas as pd

cols  = ['Maths', 'Science', 'English']
marks = pd.DataFrame(results, columns=cols, index=range(1,9))
marks['Section'] = ['A']*4 + ['B']*4   # text column, no problem

# pull numbers back for the maths
marks['Overall'] = marks[cols].to_numpy() @ weights

# Pandas groups, NumPy calculates
marks.groupby('Section')[cols].mean().round(1)

06

Quiz

Four questions. No time limit.

Question 01 Copy & View
What does a print after this code runs?
a = np.array([10, 20, 30, 40]) v = a[:2] v[0] = 99 # edit through slice c = a[[0, 1]] c[1] = 77 # edit through fancy index print(a)
B. v = a[:2] is a slice → view. v[0] = 99 writes into a → a[0] becomes 99. c = a[[0,1]] is fancy indexing → copy. c[1] = 77 only changes c. So a = [99, 20, 30, 40].
Question 02 Stacking
A has shape (3, 4) and B has shape (2, 4). Which call works, and what shape does the result have?
A. vstack adds rows: 3 + 2 = 5 rows, same 4 columns → (5, 4). hstack needs the same row count (3 ≠ 2) → fails. vstack never changes columns. hstack would need same rows, giving (3, 8) only if both had 3 rows.
Question 03 Matrix Multiply
A and B both have shape (8, 3). Which line runs without error, and what shape does it produce?
B. B.T transposes B to shape (3, 8). Then (8, 3) @ (3, 8): inner sizes both 3 → result (8, 8). Option A and C: (8, 3) @ (8, 3) has inner sizes 3 ≠ 8 → ValueError. Option D: element-wise * with shapes (8, 3) and (3, 8) can't broadcast — 3 ≠ 8 on the right.
Question 04 NumPy vs Pandas
Riya runs this code. What is mixed[0, 0]?
section = np.array(['A','A','A','A','B','B','B','B']) mixed = np.hstack([section.reshape(8,1), results]) print(mixed[0, 0])
B. When NumPy stacks mixed types, the entire array is upcast to <U32 (Unicode string). mixed[0, 0] is the string 'A'. And mixed[0, 1] is '80.6' — a string, not a float. Maths breaks. Use Pandas instead.
